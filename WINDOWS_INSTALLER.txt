BananaSplit v2.5 for Windows: installer and portable EXE

The repository's Windows v2.5 source archive is built on a Windows runner by the "Build Windows packages" GitHub Actions workflow. It installs the Rust toolchain for compilation only, builds the x64 MSVC executable, packages it with Inno Setup, and publishes both outputs as a workflow artifact with SHA-256 checksums.

Users do not need Rust, rustc, Cargo, Visual Studio, or a separate Rust runtime to run the compiled executable. The installer is user-scoped, requires Windows 10 or newer on an x64-compatible system, and does not request administrator privileges. WASAPI is part of Windows and is used directly by BananaSplit.

VB-Audio VB-CABLE is optional. It is only needed when applications should use BananaSplit virtual audio endpoints. The app detects the cable endpoints and reports when they are missing; it does not download or install third-party drivers.

The v2.5.0 packages are also checked into `version 2.5 Windows/` for direct download. The folder contains:
- bananasplit.exe (portable)
- BananaSplit-Setup-v2.5.0-x64.exe (installer)
- SHA256SUMS.txt

To get a fresh workflow build, open the repository's Actions tab, select "Build Windows packages", open a successful run, and download the "BananaSplit-Windows-v2.5.0" artifact. It contains the same three files.

The workflow also runs automatically when the Windows source archive or packaging files change. The installer and executable are not code-signed; Windows may show its normal publisher warning until a code-signing certificate is configured.
